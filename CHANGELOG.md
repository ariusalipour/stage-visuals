# Changelog

## 0.1.0-beta.1 — 2026-09-05

- First Windows x64 desktop pre-release.
- Local import, analysis, timeline correction, scoring, and MP4 export.
- Customizable transparent Stage HUD with saved defaults.
- Pointer-centred video zoom with a Fit reset control.
- Bundled media tools, fonts, branding, and native dependencies.
- Persistent projects and preferences across updates and uninstall.

Known limitations: unsigned packages, no automatic updater, and no macOS build.
